## Selected user journey

1. Open native Chat with an unassigned Conversation. Choose an eligible Topic
   deliberately; equal names have safe PARA/identity context. No implied first
   choice. Assign through the existing conditional owner; stale/revoked choices
   fail closed and unchanged uncertain retries retain their intent.
2. From that Topic, open New Conversation in the focused native dialog. Cancel
   retains Chat/draft and focus. Create/reopen/reconcile uses the existing durable
   owner and activation state; only its immutable exact created Session can open.
3. From a current or remembered linked Conversation, open Topic Files through
   the existing native slot/explorer (#344). Browse its already authorized Note,
   read a table without squeezed dates/headings, keyboard-scroll wider columns,
   switch to exact authoritative Source and back, and retain Chat/draft.

Assignment and creation are new PR366 behavior; table readability is PR367.
Current/remembered/Primary Files routing is existing behavior, not reimplemented.
The reader does not file native uploads, edit Notes or perform maintenance.
