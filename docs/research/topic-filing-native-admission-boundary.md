## Required native contract before publication integration

The public readSessionTranscriptVisibleMessageDelta is asynchronous. It provides
same-snapshot generation/entry facts for a bounded read, without a synchronous
source commit admission callback. The native v2 tool assertInvocationCurrent is
an invocation lifetime/authority fence, without an attachment/message generation
proof. Generic loadWebMedia is a bounded media reader, without a Conversation
source witness. Those contracts must not be silently promoted into one another.

A narrow extension belongs in the existing native accepted-input/transcript/media
owner. It should resolve an exact accepted user entry and canonical inbound media
in a bounded, exact agent/Session incarnation scope, then supply a trusted
synchronous admission capability for that original source. Its admission must
reject replaced/closed/protected Session, changed source/generation, foreign media
ownership and retired invocation, and keep native ownership current while the
existing Note owner performs its synchronous conditional no-replace publication.
It must reject Promise-returning commit callbacks. The opaque runtime capability
must never be JSON, model arguments, plugin config, parsed text, an arbitrary URL,
or a caller-controlled filesystem locator.

Whether implemented as a narrow guarded resolver/lease or an existing native
transaction callback, this is a public native contract change. Prepare it in an
isolated native source candidate with real SDK tests and an explicit native/plugin
release pair; do not alter the native26a qualification worktree or deployment.
Do not add a CC source mirror, second writer or lease queue to bridge the gap.
