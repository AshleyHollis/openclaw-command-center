## Existing functionality and dependency traps

**Native full-text transcript search already exists in stable 9.4.** Its [version-pinned documentation](https://github.com/openclaw/openclaw/blob/3a9d69db306cd7f081e06254cb89c4bcc14a7107/docs/concepts/session-search.md) describes transactionally indexed user/assistant text, visibility filtering, reset-aware message anchors and incomplete background reindexing. Semantic memory search is separate. Reusing this later still requires exact linked Conversation scope, archived-history coverage and authorization; an empty native result must not be represented as global absence. The CLI wrapper in #146688 searches one Gateway-selected agent per call and rejects incompatible options. None of this establishes a Notes-search implementation.

**#146984 is not independent.** Its body explicitly builds on merged [#146866](https://github.com/openclaw/openclaw/pull/146866), [#146917](https://github.com/openclaw/openclaw/pull/146917), and [#146927](https://github.com/openclaw/openclaw/pull/146927). Their merge commits are respectively `10d36d1f478a1d29df0534d268f475015910b828`, `c015302f7ff90d4c41f4753d0736dbd92ddb5e80`, and `13ffb8a5cda4d38e98792b4d3695f05e08a40766`. All three compare as `diverged` against both frozen releases. Inspect queue custody, physical database owner, route admission and completion contracts together; do not paste one consumer callback without its owner contracts. The PR reports final composed-source real-provider acceptance pending. If dependency closure becomes substantial and the route is not needed for delivery, defer the cluster.

The latest [review comments](https://api.github.com/repos/openclaw/openclaw/issues/145121/comments) say their only remaining merge checkbox is marking the PR ready for review. They report no code/security finding and accept source-runtime long-turn evidence. However, the [current-head check list](https://api.github.com/repos/openclaw/openclaw/commits/3b3b97e16535d28549d69bde0614faf40ff11cbf/check-runs?per_page=100) has the normal build/test/CI gate checks skipped; that is not a green candidate qualification.
