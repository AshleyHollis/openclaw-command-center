## UX and failure behavior

Each rendered table keeps semantic table/header/cell markup inside a labelled,
keyboard-focusable horizontal scroll region. Columns have a readable minimum
width; short headings and ISO dates do not fragment merely to fit the pane.
Long ordinary text wraps within a bounded column. Files and native Chat remain
where the host placed them; wide tables do not widen the page.

Source remains the exact original Note text. The existing sanitized Markdown
path, oversized plaintext fallback, identity/read/cancellation guards and native
pane/draft owner are unchanged. The wrapper is created only after sanitization;
no remote resources, document instructions or mutation controls are enabled.
Switching documents or Source/Reading replaces old rendered regions normally.
