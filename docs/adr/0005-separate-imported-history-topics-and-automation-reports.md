# Separate imported history, knowledge Topics and automation reports

The user approved preserving imported history separately from active conversations, and clarified that a reporting channel is not necessarily a knowledge Topic. Genuine Topics retain their dedicated Note Folder; automation reports remain native automation output with optional Topic associations, and the main-agent Chat retains its existing identity and cross-context authority outside exclusive Topic ownership.

Preserve each imported source channel's history and provenance separately even when several histories belong to one Topic. Do not replace existing active Sessions, manufacture empty Note Folders for reports, or classify an active reporting channel as archived merely because it is operational. Imported historical snapshots are read-only in the app; existing live automation conversations and delivery remain unchanged.

This is an explicit alternative to the legacy import's initial-Primary-prefix model, not permission to reinterpret existing version-1 provenance or loosen its ownership checks. The new import contract must account for all approved source history, including reporting history without Topic ownership, and preserve attachments and honest unavailable-source metadata. Native automation run summaries are not a substitute for preserved source messages. Rich Attention/notification workflows remain deferred under ADR 0004.
